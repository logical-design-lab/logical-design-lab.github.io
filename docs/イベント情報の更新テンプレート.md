# イベント情報の更新テンプレート

新しいイベント（技術書典など）に合わせて頒布情報を変えるときは、
**`_data/event.yml` の1か所だけ**を書き換えます。全巻の書籍ページに反映されます。
（過去のイベント情報は残さず、上書きで構いません）

## 記入欄（Claudeに伝える場合はこの内容をそのまま送ってください）

```
イベント名：
オンライン開催期間：
オンライン補足（例：技術書典オンラインマーケット）：
オフライン日時：
会場：
スペース番号：
スペース補足（例：最奥部）：
会場マップ画像：（あれば添付。なければ空欄）
```

## event.yml の書き方

```yaml
name: 技術書典21
online_period: 11月21日（土）〜12月6日（日）
online_note: 技術書典オンラインマーケット
offline_date: 11月23日（月・祝）11:00〜17:00
offline_note: 池袋サンシャインシティ 展示ホールD
space: せ27
space_note: 最奥部
map_image: ""        # 例: map-tc21.webp（assets/img/ に置く）。空欄なら地図は非表示
map_alt: 会場マップ（自スペース周辺）
```

## 新しい巻を追加するとき

`_data/books.yml` の先頭に1件追加し、`books/<id>/index.html` を作ります。
トップ・同人誌一覧には自動で並びます。試し読み画像は `samples` に追記すると表示されます。
